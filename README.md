# LG Safety — Site Institucional

Site institucional desenvolvido para a LG Safety,
empresa especializada em segurança, automação e
soluções para máquinas e equipamentos industriais.

## Sobre o projeto

O projeto tem como objetivo modernizar a presença
digital da LG Safety, apresentando seus serviços,
projetos, máquinas e canais de contato de forma
mais profissional e responsiva.

## Páginas

- Início
- A Empresa
- Serviços
- Máquinas
- Cases
- Contato

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Design responsivo

## Recursos

- Menu responsivo
- Catálogo de máquinas
- Filtros de cases
- Formulário de orçamento
- Integração com WhatsApp
- Layout responsivo
- SEO básico
- Animações e interações
